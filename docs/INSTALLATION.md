# Windows 시험 설치

현재 빌드는 내부 시험용이며 코드 서명이 없다. Windows에서 게시자를 확인할 수 없다는 경고가 나올
수 있으므로 배포 전에는 학교가 관리하는 코드 서명 인증서와 배포 절차를 확정한다. 보안 기능을 끄거나
여러 PC에 무인 배포하지 않는다.

## 연결 확인

1. 설치 후 위젯에서 **학교 계정으로 연결**을 누른다.
2. 기본 브라우저에서 `https://sjows.vercel.app/widget/connect`가 열리는지 확인한다. 연결 요청은 네트워크 상태에 따라 최대 15초 정도 걸릴 수 있다.
3. 브라우저가 연결 코드를 자동으로 확인하면 표시된 코드·PC 이름이 위젯과 일치하는지 보고 **승인하기**를 누른다. 정상 흐름에서는 코드를 다시 입력하거나 별도로 확인할 필요가 없다.
4. 위젯이 오늘과 향후 7일 일정을 표시하는지 확인한다.
5. 온라인 교무실에서 시험 일정을 수정한 뒤 위젯의 **새로고침**으로 반영되는지 확인한다.
6. 트레이의 **로그아웃** 뒤 일정이 사라지고 다시 연결 화면이 나오는지 확인한다.

## 개인 일정 확인

1. **+ 개인 일정**을 눌러 제목·날짜·시간·메모를 입력하고 저장한다.
2. 목록·월간·주간 보기에 분홍색 개인 일정이 같은 날짜에 표시되는지 확인한다.
3. 개인 일정 상세에서 수정과 삭제가 동작하는지 확인한다.
4. 앱을 완전히 종료했다 다시 열어 개인 일정이 유지되는지 확인한다.
5. 학교 계정에서 로그아웃한 뒤에도 개인 일정만 남는지 확인한다.

개인 일정은 현재 Windows 사용자의 Tauri 앱 데이터 폴더에 있는 `personal-events.json`에만 저장되며
SJOWS API 요청에는 포함되지 않는다. 이 파일은 별도 암호화되지 않으므로 민감정보를 기록하지 않는다.

## 창과 보기 방식 확인

1. 창 상단의 학교명·날짜 영역을 끌어 창을 이동한다.
2. 창의 네 가장자리와 네 모서리를 끌어 크기를 조절한다. 오른쪽 아래에는 작은 조절 표시가 있다.
3. **목록**, **월간**, **주간**을 차례로 선택해 일정이 같은 날짜에 표시되는지 확인한다.
4. 이전·다음 화살표와 **오늘** 버튼으로 표시 기간을 이동한다.
5. 창 폭을 좁혔을 때 월간·주간 보기가 가로 스크롤로 유지되는지 확인한다.

시험 중에는 DB 연결 문자열, `WIDGET_TOKEN_SECRET`, 액세스 토큰 또는 갱신 토큰을 화면 캡처나 로그에
남기지 않는다. 문제가 생기면 위젯에 표시된 오류 코드와 사용자용 메시지만 기록한다.
