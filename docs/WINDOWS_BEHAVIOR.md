# Windows 표시 검증 기록

현재 상태: 구현 전 검증 대기. 이 저장소는 macOS에서 작성되었고 Rust 도구 체인이 설치되어 있지 않아 Windows 네이티브 실행은 수행하지 못했다.

Windows 11 x64 시험에서 다음을 실제로 기록한다.

1. 기본 창은 항상 위가 꺼진 상태로 다른 일반 창 뒤에 머무는지 확인한다.
2. Win+D, 모든 창 최소화, Explorer 재시작 후의 표시를 각각 확인한다. `alwaysOnTop: false`는 바탕화면 계층 고정을 보장하지 않는다.
3. 트레이의 표시/숨기기, 새로고침, 항상 위, 설정, 로그아웃, 종료를 확인한다.
4. 로그인 자동 실행은 사용자가 설정에서 선택한 뒤에만 등록하고, 제거 후 등록이 사라지는지 확인한다.
5. 두 번째 실행이 기존 창을 표시하고 종료되는 단일 인스턴스 동작, 모니터 분리 후 화면 안 복귀, 100~200% 배율을 확인한다.

바탕화면 고정이 비공식 Explorer 창 계층에 의존할 경우 사용한 Windows API, Explorer 재시작 뒤 복구 동작, 지원 Windows 버전을 이 문서에 추가한다.
